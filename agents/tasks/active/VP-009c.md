# VP-009c — Removable Teller connection probe

## Status
`ACTIVE`

## Owner
Banking Agent (Integration/Review separate)

## Purpose
A tiny check that proves the certificate, mutual TLS and credentials work end to end, designed to be deleted before production.

## Scope
- Single file `internal/banking/probe.go` plus one route-registration line.
- Registered only when `TELLER_PROBE_ENABLED=true` and `TELLER_ENV=sandbox` and the app environment is not production.
- Makes one read-only Sandbox call and returns `{ok:true}` or a typed error; never returns tokens, cert details or provider payloads.
- Backend refuses to start if the flag is enabled in production.

## Out of Scope
Any real-bank (Development) call, persistence, UI. Removal itself happens at production readiness.

## Dependencies
VP-009b COMPLETED.

## Requirements
1. Requires an authenticated Foundation user and is rate limited.
2. Removal = delete `probe.go` and its one registration line; documented in the task and README.
3. No other code may import the probe.

## Acceptance Criteria
- [ ] Probe returns ok against the fake and Sandbox client.
- [ ] Flag on in production prevents startup (tested).
- [ ] Route absent when flag off (tested).
- [ ] Deleting the file and the one line still builds and passes tests.

## Testing Requirements
Unit and startup-guard tests; build-after-removal check.

## Shared Resource Impact
Canonical User Identity: NO (reads Foundation user only). Other domains: NO.

## Database Impact
NONE

## Contract Impact
NEW CONTRACT (dev-only endpoint, explicitly non-stable)

## Security Considerations
Default off; must never be reachable in production.

## Financial Correctness Considerations
Not applicable.

## Blockers
Owner has not yet confirmed Teller certificate issuance from the Teller dashboard or the AWS region.
