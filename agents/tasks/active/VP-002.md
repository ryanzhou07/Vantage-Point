10. CI uses pinned Node, pnpm, Go, and Supabase tooling and frozen frontend dependencies. Run frontend lint/typecheck/tests/build and backend formatting/vet/test/build. Formatting drift and actual test failures must fail CI.
11. Establish a frontend test command if absent. The scaffold has no testable feature logic yet: document test absence explicitly rather than adding meaningless tests. Future feature tests must execute and failures must block CI.
12. CI starts a clean disposable database, applies all committed migrations from zero, and executes available schema validation. Preserve the check before application tables exist and extend it when schema is introduced.
13. Add basic secret scanning with redacted findings and dependency scanning supported by the manifests; document coverage and limitations. Checks use synthetic/fake providers as introduced and never production provider calls.
14. Document check names and recommended main branch protection without claiming remote repository settings were changed. Record actual PR CI results before completion; static workflow validation does not substitute for hosted CI.
