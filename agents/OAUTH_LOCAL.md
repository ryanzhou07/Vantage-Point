# VP-003 local Google smoke setup

Use a Google Cloud **Web application** OAuth client in a nonproduction project. Configure consent/testing audience and add your Google account as a test user if in Testing mode. Authorized JavaScript origin: `http://localhost:3000`. Authorized redirect URI: `http://127.0.0.1:56321/auth/v1/callback` (Supabase handles provider callback, then app PKCE callback). Register these exact values, including host/port/path. The app redirect allowlist is `http://localhost:3000/auth/callback`. No wildcard redirects.

In the active worktree, copy `.env.oauth.example` to ignored `.env.oauth.local`, enter GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET locally, and never paste values into chat, logs, screenshots or Git. `scripts/local-db.sh` loads this file privately; stop/start the Vantage-Point stack after changing credentials. Only port563xx/project `vantage-point-local` is managed. Missing credentials use offline fixtures only for deterministic CI; fake values cannot pass real Google sign-in.

Use pinned repository tools. `pnpm db:start`, `pnpm db:validate`, `pnpm auth:integration` run local fixtures/migration/RLS checks; db:validate resets only disposable local data. Obtain local public anon key from Supabase status **privately** and configure ignored `apps/web/.env.local` with NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:56321, NEXT_PUBLIC_SUPABASE_ANON_KEY and NEXT_PUBLIC_API_URL=http://localhost:8080. Never place a service-role/Google secret in NEXT_PUBLIC variables. Backend requires SUPABASE_URL, SUPABASE_ANON_KEY, WEB_ORIGIN=http://localhost:3000; run `go run ./cmd/api` in services/backend. Start frontend with `pnpm dev`.

Actual smoke: open localhost:3000 at desktop and mobile viewport; loading resolves, Continue with Google starts Google consent, select configured test account, return via Supabase and app callbacks, confirm signed-in profile and /me 200. Sign out, verify signed-out UI and no further authenticated profile requests; reload remains signed out. Test canceled consent and callback with no code to see safe error/retry. Record date/environment/viewport/results without identity/token screenshots. The owner must interact with Google account login/consent as needed. Automated fixtures are separate and do not satisfy real OAuth smoke.
